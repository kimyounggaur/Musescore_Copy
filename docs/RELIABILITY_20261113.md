# ScoreForge 점검 문서 반영 기록

기준: 사용자가 첨부한 「ScoreForge 점검 결과 수정·보완할 점」. 작업일: 2026-11-13.

## 운영에서 확인한 사항과 유지 결정

- A3: 현재 연결 프로젝트는 `lesson-designer`이며 회원과 관리자 권한을 공유한다. 다른 앱의 회원·자료를 손상시키지 않도록 이번 배포에서 프로젝트와 주소를 유지했다. 전용 프로젝트 신규 생성·회원/악보 이전·기존 공유 링크 호환은 별도 이전 작업으로 남는다.
- 2026-11-13 실제 Security Advisor: 유출 비밀번호 검사 비활성화 경고 1개. 다른 앱의 RLS 활성/정책 없음 정보 3개. `scores`의 소유자 쓰기 정책과 공유 조회 구조를 읽기 전용으로 점검했다. 다른 앱의 정책을 변경하지 않았다.
- C15: 비밀번호 재설정 요청·복구 화면은 구현했다. 메일 발송과 운영 Redirect URL은 서버 설정에 의존한다. 공용 Auth 계정 전체 삭제는 다른 앱 자료도 삭제할 수 있어 제공하지 않으며, 안내 화면에 제한을 명시했다. 개별 클라우드 악보 삭제는 기존 목록에서 가능하다. 전체 탈퇴는 전용 계정 이전 후 서버 측 재인증·세션 폐기·삭제를 함께 구현해야 한다.
- D3: 표시 이름 ScoreForge 유지. 기존 설치 앱·로컬 악보·배포 링크를 보호하기 위해 저장소/호스팅 주소는 바꾸지 않았다. 저장소 전체에 임의 라이선스를 부여하지 않았다.
- D4: 기존 테마 CSS의 전면 통합과 레거시 코드 전체 재정렬은 수행하지 않았다.
- B10: 시스템 그림 재사용과 병목 제거는 적용했으나, 전역 레이아웃 계산과 SVG 호스트 DOM 전체 교체는 남는다. 완전한 부분 DOM 갱신은 후속 최적화다.

## 검증과 한계

- Node 회귀 검사, 구문 검사, 내용 해시·릴리스 검사, 서식 검사 실행. 최종 수와 CI 결과는 해당 커밋의 Actions 기록을 기준으로 한다.
- 실제 Chromium 검사는 이 실행 환경의 Unix socket 제한으로 시작하지 못했다. 연결 브라우저도 시간 초과하여 화면 기반 검증을 완료하지 못했다. CI에 기본 Chromium 검사를 연결했다.
- 실제 한글 입력기, 운영체제 파일 저장창, MIDI 장치, 실제 스피커 청취, 다른 악보 프로그램 호환은 확인하지 못했다. 관련 핵심 동작은 모델·모의 브라우저 API 회귀 검사로 검증했다.
- 밀집된 200마디 4중주 시험에서 직렬화 크기: 이전 약 2,144,667바이트 → 735,568바이트. 환경별 조판 시간 변동이 커 일정한 속도 향상 배율은 주장하지 않는다.
