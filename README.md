# 🎼 ScoreForge — 쉬운 웹 악보 에디터

MuseScore의 핵심 기능(음표 입력 → 편집 → 재생 → 저장/내보내기)을 브라우저에서 바로 쓸 수 있게 만든
**설치·빌드 없는 정적 웹앱**입니다. `musescore-web-vibecoding-guide.md`의 아키텍처 원칙
(유리수 시간 모델, 레이아웃/렌더 분리, 단일 편집 통로, MuseScore 단축키 관례)을 따릅니다.

## 실행 방법

| 방법 | 하는 법 |
|---|---|
| 그냥 열기 | `index.html` 더블클릭. 파일/악보 편집은 가능하지만 설치·서비스 워커는 HTTPS 또는 localhost 필요 |
| 로컬 서버 | `npm run serve` 후 `http://127.0.0.1:8000` |
| 배포 | 기존 [Vercel 앱](https://musescore-copy.vercel.app), 정적 파일 배포. `vercel.json`에 보안·캐시 헤더 포함 |

Bravura 폰트와 Supabase/smplr 라이브러리는 로컬에 포함됩니다. 온라인으로 한 번 연 뒤에는 앱 셸과 마지막 자동 저장 악보를 오프라인에서도 열 수 있습니다. 악기 샘플은 별도 네트워크 자료이며, 미리 캐시되지 않은 음색은 내장 신스로 재생합니다.

## v3 보강 사항

- **기보**: 32분·64분·겹온음표, 겹점, 화음의 개별 음 편집, 마디별 조표/박자/음자리표, 알토·테너·8vb 음자리표, 8va/8vb 선.
- **마디**: 삽입/범위 삭제/분할/합치기/못갖춘마디, 파트 보기의 여러 마디 쉼표, D.C./D.S./Coda/Fine/To Coda, 트릴·모르덴트·턴과 재생.
- **조판·출력**: 실제 페이지/연속 보기, 제목·부제·작곡가·작사가·저작권, 텍스트 충돌 회피, 조판 스타일, 자체 완결 SVG·300dpi PNG·브라우저 인쇄/PDF.
- **입출력·재생**: 다중 파트/피아노 2단/성부/잇단음표 MusicXML 및 MXL, MIDI 가져오기와 양자화 선택, 파트별 SMF type 1, 50~200% 속도/범위 반복/예비박/페르마타/실시간 믹서.
- **클라우드**: 회원별 악보 저장/검색/목록/공유, 갱신 시각 기반 충돌 감지, 오프라인 저장 대기, 익명 읽기 전용 공유와 사본 만들기. [연동·권한 안내](supabase/README.md).
- **사용성**: KO/EN, 4개 테마, 모바일 하단 팔레트·길게 누르기·핀치 줌, 포커스 관리, 통합 단축키, 변경 이력 라벨과 연속 편집 병합.

단계별 변경과 검증/제약은 [구현 기록](IMPLEMENTATION_V3.md), 실제 Supabase 검증은 [검증 기록](docs/SUPABASE_V3_VERIFICATION.md)을 참고하세요.

## 주요 기능

- **음표 입력 4가지 방법**: 보표 클릭(고스트 미리보기) · 키보드 A~G · 화면 피아노 건반 · **스피디 입력(숫자 1타 입력, Q)**
- **편집**: 선택/방향키 탐색, **범위 선택(Shift+클릭·Shift+←→)**, **복사/붙여넣기/잘라내기(Ctrl+C/V/X)**, 드래그로 음높이, 음길이 변경, 점음표, 임시표(♯♭♮), 화음(Shift), 타이, **잇단음표(Ctrl+3~9)**, 가사, 삭제
- **표현 기호 (가이드 Phase 4)**: 이음줄(슬러, 시스템 경계 분할·음표 회피), 셈여림 pp~ff, 크레셴도/디미누엔도 쐐기, 아티큘레이션(스타카토·테누토·악센트·마르카토, 줄→칸 밀기·세로 쌓기), 페르마타, **템포·리허설 마크·스태프 텍스트** — 재생(velocity/gateTime/레가토/선형 보간/템포맵)에 반영
- **조판**: 빔 자동 묶음(박 단위·4/4 8분음표 2박 병합), 마디 경계 자동 타이 분할, 임시표 자동 표기 규칙, 자동 줄바꿈/양쪽 정렬
- **레이아웃·스타일**: A4/Letter·가로/세로, 여백, 마디/줄, 음표 간격, 보표/시스템 간격, 빔 두께, 시스템/페이지/섹션 브레이크
- **작업 패널**: 오른쪽 속성 패널(보임·색상·오프셋·스템·음표머리·텍스트/기호), 내비게이터(F12), 타임라인(F11), 마디/리허설 이동(Ctrl+F/G)
- **재생**: smplr 사운드폰트/샘플러 실제 악기 음색(피아노·일렉피아노·뮤직박스·오르간·현악기·플루트·8비트, 오프라인/실패 시 내장 신스 폴백), 재생 커서·음표/건반 하이라이트, 메트로놈, 선택 위치부터 재생, 템포 조절
- **악보 설정**: 음자리표(높은/낮은), 조표 15종, 박자(2/4·3/4·4/4·6/8, 내용 유지 재배치), 조옮김(반음~옥타브)
- **파일**: 저장/열기(.json), MusicXML/MXL 및 MIDI 가져오기·내보내기, SVG/PNG, 인쇄/PDF, 브라우저 자동 저장, 드래그&드롭
- **가져오기 리포트**: 지원 요소는 보존하고, 지원하지 않는 항목/양자화/성부 제한은 요약 리포트에 표시합니다. 원본 MuseScore 전체 기능을 완전히 재현하는 변환기는 아닙니다.
- **실행 취소/다시 실행** 최대 200단계, 한국어/영어 UI, 반응형, 시작 가이드·데모 악보 4곡

## 코드 구조 (가이드의 레이어 규칙)

```
index.html        앱 셸(툴바·다이얼로그·피아노)
css/style.css     디자인 토큰(다크 작업실 + 흰 종이), 반응형, 인쇄
js/core.js        ★ 도메인: Fraction 시간, tpc식 음높이 철자, 악보 트리,
                    fillGap 편집 연산, rebar, 조옮김, 스냅샷 undo/redo
js/engrave.js     ★ 조판: SMuFL(Bravura) 글리프 + 폴백 패스, 레이아웃(간격·줄바꿈·justify),
                    빔/타이/임시표/덧줄 렌더, 히트 테스트, 고스트/커서 오버레이
js/playback.js    ★ 재생: 악보→이벤트 컴파일(타이 병합), smplr 샘플러+신스 폴백, 룩어헤드 스케줄러,
                    메트로놈, MIDI(SMF) 내보내기
js/io.js          저장/열기(JSON), MusicXML 4.0 내보내기, 자동 저장, 데모 악보 DSL
js/app.js         UI 배선: 단축키, 마우스/드래그, 피아노, 재생 커서, 다이얼로그, 토스트
js/input.js       음표/건반/스피디 입력
js/editing.js     선택 범위, 음표 편집과 기호 적용
js/panels.js      속성·설정·믹서·탐색 패널
js/keymap.js      단축키 원본, 명령 팔레트·도움말
js/ui-dialog.js   비동기 앱 다이얼로그와 포커스 복원
js/ui-v3.js       마디·기보·모바일·재생 컨트롤
js/export-ui.js   SVG/PNG/인쇄와 MIDI 가져오기 옵션
js/auth.js        Supabase 인증·관리자 UI
js/cloud.js       소유자 악보, 충돌 감지, 공유, 오프라인 대기
js/i18n.js        KO/EN 문자열·사용자 콘텐츠 보존
js/pwa.js, sw.js  설치·업데이트·앱 셸 및 제한된 샘플 캐시
js/config.js      배포용 공개 Supabase 설정 (비밀 키 금지)
vendor/           고정 버전 외부 라이브러리·라이선스·해시
```

의존 방향은 `app → (engrave, playback, io) → core` 한 방향입니다.
악보를 바꾸는 모든 동작은 `core.mutate()` 한 통로만 지나가므로 undo가 항상 안전합니다.

## 개발·검증

`npm run check`, `npm test`는 빌드나 패키지 설치 없이 Node에서 실행합니다. 브라우저 회귀는 `tests/browser.html`, 추가 UI/PWA/클라우드 검증은 `tests/verify-*.mjs`와 `tests/ui-v3.test.mjs`에 있습니다. Playwright는 선택 개발 도구이며 실행 시 `PLAYWRIGHT_MODULE`로 설치 경로를 지정할 수 있습니다.

배포 전 `node tests/gen-readme-keys.mjs`와 `node tests/prepare-release.mjs`를 실행하세요. 앱 셸 파일 변경 시 `js/version.js`와 `sw.js`의 버전을 함께 올려야 합니다. 사용자가 업데이트를 선택하기 전에는 기존 셸을 유지합니다. 버전 없는 JS에 장기 immutable 캐시를 적용하지 않습니다.

`js/config.js`에는 Project URL과 publishable/anon 공개 키만 들어갑니다. `service_role`, `sb_secret_` 또는 DB 비밀번호는 넣지 않습니다. 다른 프로젝트로 옮길 때는 Supabase SQL/설정과 Vercel CSP의 허용 도메인을 함께 확인하세요.
